Build a backend for semantic search over help-center articles.

Article embeddings come from an external embedding model that outputs vectors with exactly 1536 dimensions. Callers always supply embeddings of that size.

Write this schema to `convex/schema.ts`, adding a vector index named `by_embedding` over the `embedding` field so articles can be searched by similarity:
```ts
import { defineSchema, defineTable } from "convex/server";
import { v } from "convex/values";

export default defineSchema({
  articles: defineTable({
    title: v.string(),
    body: v.string(),
    embedding: v.array(v.float64()),
  }),
});
```

Create a public action `searchArticles` in `convex/index.ts` that:
- Takes arguments `{ embedding: number[], limit: number }`. Callers always pass an integer `limit` between 1 and 50.
- Finds the `limit` articles most similar to `embedding` using the vector index
- Returns an array of objects with exactly these fields: `{ _id: Id<"articles">, title: string, score: number }`, where `score` is the article's similarity score for this search
- Orders the results from most to least similar
- Returns an empty array when there are no articles

Load the matching articles only by the IDs the search returns; don't query the `articles` table any other way. Only `searchArticles` may be callable by clients, so make any helper functions internal.
